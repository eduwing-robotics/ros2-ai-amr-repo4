# 화면 구성 (UI Views)

## 공통 영역

| 영역 | 역할 |
| --- | --- |
| Top | 연결 상태, 출입 집계, 안전 이벤트와 운영 요약을 표시합니다. |
| Left | View 이동, 로봇 선택과 선택 로봇 상태를 표시합니다. |
| Right | 수동 주행, 긴급정지, 복귀와 지게차 제어를 적용했습니다. |
| Bottom | Global CCTV, 로봇 카메라와 최근 운영 로그를 표시합니다. |

공통 영역은 View 전환 이후에도 선택 로봇과 최신 서버 상태를 유지합니다.

## 대시보드 화면 (Dashboard View)

공장, 로봇, Map/Nav2, Camera·AI와 시스템 상태를 요약해 표시합니다.
출퇴근·방문자 현황과 최근 운영 로그를 함께 표시합니다.

## 공장 화면 (Factory View)

전체 2D 맵과 3D 공장 시점을 표시합니다. 로봇, 인원, 팔레트, 컨베이어,
충전 구역과 이벤트 위치를 가상 공장에 표시합니다.

## 로봇 화면 (Robot View)

선택 로봇의 상태, 배터리, 속도, 좌표와 명령 결과를 표시합니다.
수동 주행, 정지, 복귀와 TB3-03 지게차 제어를 적용했습니다.

## 지도 상태 화면 (Map Status View)

로봇 위치와 방향, 현재·다음·완료 Waypoint와 Route를 표시합니다.
Nav2 임무, 목표 결과, 장애물과 복구 상태를 함께 표시합니다.

## 카메라·AI 화면 (Camera·AI View)

Global CCTV와 TB3 카메라의 영상 및 실제 프레임 수신 상태를 표시합니다.
AI 모델 상태와 화재·쓰러짐·안전모 미착용 감지 결과를 표시합니다.

## 안전 이벤트 팝업 (Safety Event Popup)

이벤트 유형, 위치, 감지 주체, 신뢰도, 현장 이미지와 권장 조치를 표시합니다.
확인과 조치 완료 결과를 이벤트 목록과 운영 로그에 적용했습니다.
