# Shared Source Security

## 적용한 정리

- 원본에 지정되어 있던 두 사설 서버 주소를 `127.0.0.1:8000`으로 교체했다.
- 관제, 카메라 WebSocket은 `ws://127.0.0.1:8000`을 기본 호스트로 사용한다.
- REST와 스냅샷 상대 경로는 `http://127.0.0.1:8000`을 기본 주소로 사용한다.
- 직원·방문자 이름과 ID, 사진·스냅샷 URL을 포함하는 Console 로그를 제거하거나
  이벤트 유형과 처리 상태만 남도록 축약했다.
- 송수신 전체 JSON과 REST request body를 Console에 직접 출력하지 않는다.

## 비밀정보 검사

복사 대상 C# 파일에서 API Key, 인증 Token과 비밀번호를 검사했으며
하드코딩된 해당 비밀정보는 발견되지 않았다. 이 공유본에는 인증 정보를
추가하지 않는다.

## 제외 자산

얼굴 이미지와 스냅샷 원본은 개인정보 및 생체정보 노출 위험 때문에 제외했다.
PPT와 영상은 소스 검토에 필요하지 않고 대용량·저작권 자료일 수 있어 제외했다.
3D 모델과 폰트는 용량, 라이선스와 재배포 조건을 별도로 확인해야 하므로 제외했다.
Scene과 Prefab도 전체 실행 프로젝트 및 참조 자산을 재배포하지 않기 위해 포함하지 않았다.

## 배포 시 주의

이 디렉터리는 코드 검토와 협업을 위한 공유용 정리본이며 완전한 Unity 실행
프로젝트가 아니다. 실제 배포에서는 환경별 서버 주소, TLS(`https`/`wss`),
인증·인가, 비밀정보 저장소, 네트워크 접근 제어와 로그 보존 정책을 별도로
구성해야 한다. 운영 주소나 자격 증명을 소스 코드에 하드코딩하지 않는다.
