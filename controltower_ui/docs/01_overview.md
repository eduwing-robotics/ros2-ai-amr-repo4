# 01. Overview

## 개발 배경

고정 CCTV와 사람 중심 감시는 공장 사각지대와 반복 확인 업무를 줄이기 어렵습니다. 안전모 미착용, 화재와 쓰러짐은 발견이 늦을수록 위험이 커지고, 로봇·카메라·AI·서버 상태가 분리되면 운영자가 상황을 빠르게 판단하기 어렵습니다.

이 프로젝트는 TurtleBot3의 이동성, AI 인식, ROS2·Nav2 자율주행과 Unity 통합 관제를 연결해 감지부터 확인·제어·기록까지 이어지는 운영 흐름을 구현했습니다.

## 해결하려는 문제

- 로봇·카메라·AI·출입 정보가 여러 시스템에 분산된 문제
- 로봇 위치와 Route·Waypoint 진행 상태를 현장 화면과 함께 보기 어려운 문제
- 위험 이벤트 감지 이후 확인·조치·이력 관리가 분절되는 문제
- 운영자 명령 요청과 실제 로봇 실행 결과를 구분해야 하는 문제
- ROS 좌표, 서버 상태 문자열과 Unity 화면 표현의 해석 차이
- 화면을 전환하거나 부분 메시지를 수신할 때 정상 상태가 초기화되는 문제

## 사용자 요구사항

| ID | 요구사항 | 기능 영역 |
|:---|:---|:---|
| UR-01 | 로봇은 공장을 순찰할 수 있어야 한다. | 자율주행 |
| UR-02 | 로봇은 직원을 구분할 수 있어야 한다. | 안면인식 |
| UR-03 | 로봇은 규정 위반을 알릴 수 있어야 한다. | AI 위험 감지 |
| UR-04 | 로봇은 응급 상황을 알릴 수 있어야 한다. | AI 위험 감지 |
| UR-05 | 로봇은 장애물을 인식할 수 있어야 한다. | 자율주행 |

| UR-08 | 관리자는 로봇 상태를 모니터링할 수 있어야 한다. | 통합 관제 |
| UR-09 | 로봇은 물품을 운반할 수 있어야 한다. | 지게차 |

## 운영 시나리오

1. 출퇴근 얼굴 인식과 출입 기록
2. 물류센터 순찰과 장애물 대응
3. 안전모 미착용 감지와 사건 기록
4. 화재·쓰러짐 감지와 현장 확인
5. 배터리 임계 시 충전소 복귀와 임무 인계
6. 관제 수동 조작·긴급정지와 승인된 재개

Global Camera가 위험을 감지하면 가용 로봇을 현장에 파견하고, 순찰 로봇이 직접 감지하면 현장에서 정지해 촬영하도록 시나리오를 구분했습니다.

## 팀 구성

| 파트 | 팀 구현 범위 | Unity에서 사용하는 결과 |
|:---|:---|:---|
| AI Perception | 안면·객체·안전 이벤트 감지 | 이벤트 유형, 좌표, 신뢰도, Snapshot |
| SLAM / Navigation | 위치 추정, 경로 계획, 순찰·도킹 | Pose, Route, Waypoint, Nav2·복구 상태 |
| Server / DB | REST·WebSocket, 데이터 저장, 명령 중계 | 조회 응답, 실시간 상태, 명령 ACK |
| Hardware | 로봇, 충전 장치, TB3-03 지게차 확장 | 장치 상태와 명령 결과 |
| Unity ControlTower | 통합 시각화와 운영자 제어 UI | 공통 관제 영역과 중앙 View |

## 개인 담당

- Unity 관제 UI 정보 구조와 공통 레이아웃 설계
- Dashboard / Factory / Robot / Map Status / Camera View 구현
- REST API / Control WebSocket / JPEG Camera Stream 연동
- 로봇 상태·경로·출입·이벤트·카메라 시각화
- 순찰·재개·복귀·긴급정지·초기화와 수동 제어 요청 UI
- TB3-03 리프트와 팔레트 운반 상태 시각화
- Runtime Cache, 부분 데이터와 화면 재진입 안정화
- Blender·Unity 모델 제작 또는 수정·통합과 공장 배치
- UI 한글화, 공개 시연 화면과 문서 정리

## 구현 원칙

- 최종 Runtime에는 실제 서버·카메라 수신값만 표시합니다.
- 응답이 없거나 필드가 누락되면 값을 임의 생성하지 않습니다.
- HTTP 성공을 실제 장치 실행 완료로 간주하지 않습니다.
- 명령 ACK 또는 후속 `ROBOT_STATUS`로 Accepted·Rejected·상태 변화를 구분합니다.
- View 전환 중에도 선택 로봇, 최신 상태, 경로, 카메라와 운영 로그를 유지합니다.

## 협업 구조

Unity ControlTower는 AI, ROS2·Nav2, Server·DB와 Hardware 파트의 데이터를 한 화면에서 연결하는 통합 관제 역할을 담당했습니다. 저는 각 파트의 상태와 이벤트를 운영자가 이해하기 쉬운 화면과 제어 흐름으로 구성했습니다.
