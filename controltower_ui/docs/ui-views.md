# UI Views

## 공통 영역

| 영역 | 표시 및 동작 |
| --- | --- |
| Top | 시스템 연결 상태, 출퇴근·방문자 집계, 안전 이벤트와 운영 요약 |
| Left | Dashboard, Factory, Robot, Map Status, Camera·AI View 이동과 로봇 선택 |
| Right | 선택 로봇 제어, 수동 주행, 긴급 정지, 복귀 및 지게차 제어 |
| Bottom | Global CCTV와 로봇 카메라 미리보기, 최근 상태 정보 |

공통 영역은 현재 선택 로봇과 서버 수신 상태를 공유한다. View를 전환해도
로봇별 최신 위치, 상태와 정상 경로 캐시를 유지한다.

## Dashboard View

- 공장, 로봇, Map/Nav2, Camera·AI와 시스템 상태 요약
- 로봇별 준비 상태, 배터리와 현재 임무
- 출근, 퇴근, 방문자 및 최근 출입 요약
- 최근 운영 로그와 로봇·제어·카메라·시스템·오류 필터
- 각 요약 영역에서 관련 상세 View로 이동

## Factory View

- 전체 2D 맵과 3D 공장 시점 전환
- 로봇, 인원, 팔레트, 컨베이어와 충전 구역 상태 표시
- 상단·정면·측면 3D 카메라 제어
- Global CCTV와 미니맵
- 안전 이벤트의 공장 위치 표시

## Robot View

- 선택 로봇의 상태, 배터리, 속도와 좌표
- 순찰 타임라인, 최근 명령 결과와 경고
- 자동 명령, 수동 주행, 정지와 충전소 복귀
- TB3-03 지게차 리프트와 팔레트 운반 상태

## Map Status View

- ROS 좌표를 맵 좌표로 변환한 로봇 위치와 방향
- 현재, 다음, 완료 Waypoint 및 경로 구간 강조
- Nav2 임무 상태, 목표 결과와 재계획 정보
- 장애물 및 복구 상태
- View 재진입 시 저장된 최신 상태와 경로 즉시 재적용

## Camera·AI View

- Global CCTV와 TB3 카메라 선택
- 연결 상태와 별도로 마지막 실제 프레임 적용 시각 표시
- AI 모델 및 스트림 상태
- 안전모 미착용, 화재, 쓰러짐 등의 이벤트 정보
- 서버가 제공한 이벤트 스냅샷 표시

## 이벤트 팝업

- 실시간 이벤트 제목, 유형, 위치, 감지 주체, 신뢰도와 권장 조치 표시
- 서버 스냅샷 표시와 대기 이벤트 목록 탐색
- 확인, 조치 완료, 닫기 동작
- 확인 요청 이후 `alert_ack_result`를 수신해 처리 결과 반영
