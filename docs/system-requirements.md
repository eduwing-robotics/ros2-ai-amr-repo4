# 시스템 요구사항

사용자 요구사항을 구현·검증 가능한 단위로 분해한 시스템 요구사항(System Requirement) 14건입니다. 모든 항목의 우선순위는 `R`(Required)입니다.

| ID | 기능 | 요구사항 |
| --- | --- | --- |
| SR_01 | 공장 순찰 기능 | 지정된 순찰 구역을 반복적으로 이동하고, 순찰 중 현재 위치를 관리자에게 전송하며, 장애물 발생 시 회피 후 순찰을 계속 수행한다. |
| SR_02 | 직원 출퇴근 구분 기능 | 직원을 인식해 출퇴근을 체크하고, 직원·외부인 및 출근·퇴근을 구분한다. |
| SR_03 | 규정 위반 감지 기능 | 작업자의 안전 규정 위반 여부를 감지한다. 대상 규정 위반은 안전모 미착용이다. |
| SR_04 | 응급 상황 감지 기능 | 공장 내 작업자 쓰러짐, 화재 경보, 정전 등의 응급 상황을 감지한다. |
| SR_05 | 장애물 인식 기능 | 이동 중 전방 장애물을 감지하고, 정적 장애물(적재물)과 동적 장애물(지게차·다른 로봇)을 분류한다. |
| SR_06 | 장애물 회피 기능 | 정적 장애물은 우회 경로를 생성해 주행하고, 동적 장애물은 즉시 정지한 뒤 사라지면 기존 경로 이동을 재개한다. |
| SR_07 | 긴급 정지 기능 | 관리자 명령, 배터리 이상, 통신 이상 등의 이상 상황에서 로봇은 즉시 정지한다. |
| SR_08 | 관제 알림 기능 | 안전모 규정 위반, 쓰러짐 등 응급 상황, 정적·동적 장애물, 배터리 부족, 통신 상태 등 알림이 필요한 상황을 관제에 전송한다. |
| SR_09 | 상태 모니터링 기능 | 배터리, 주행 속도, 순찰, 경고, 통신, 작업 상태를 실시간으로 모니터링할 수 있어야 한다. |
| SR_10 | 실시간 위치 표시 기능 | 맵에 현재 위치, 이동 경로, 목표 위치, 순찰 구역, 응급 상황 위치를 표시한다. |
| SR_11 | 자동 충전 기능 | 배터리를 실시간으로 확인하고, 기준에 따라 신규 작업 가능 여부를 판단하며, 배터리 부족 시 충전 스테이션으로 이동한다. 충전 완료 후 이전 임무를 재개한다. |
| SR_12 | 데이터 저장 기능 | 순찰, 규정 위반, 응급 상황, 당시 카메라 캡처 등 주요 이벤트를 데이터베이스에 저장한다. |
| SR_13 | 데이터 조회 기능 | 관제 시스템에서 날짜·시간·종류 기준으로 저장된 로그와 이벤트 기록을 조회한다. |
| SR_14 | 멀티 로봇 협업 | 로봇 장애 발생 시 다른 로봇이 순찰 임무를 이어받을 수 있어야 한다. |

## 자동 충전 기준

최종 요구사항 문서의 배터리 기준은 다음과 같습니다.

| 배터리 상태 | 동작 |
| --- | --- |
| 40% 이상 | 새로운 작업 수행 가능 |
| 30~40% | 기존 작업 완료 후 새로운 작업 가능 여부 확인 |
| 30% 미만 | 충전 스테이션으로 이동 |
| 충전 완료 후 | 이전 임무 재개 |

구현 시 실제 운용 임계값은 로봇 자율주행 정책과 안전 여유를 고려해 조정될 수 있습니다.
