# 운영 시나리오

본 프로젝트는 아래 6개 운영 시나리오를 기준으로 설계·구현·검증했습니다.

## Scenario 1. 작업자 출퇴근 얼굴인식

1. 작업자가 물류센터 출입구에 설치된 카메라 앞에 섭니다.
2. 카메라가 작업자의 얼굴을 확인합니다.
3. AI 얼굴인식 시스템이 등록된 작업자 정보와 비교합니다.
   - **등록된 작업자**인 경우
     1. 출근 또는 퇴근을 기록합니다.
     2. 서버에 출입 정보를 저장합니다.
     3. 출입 승인 메시지를 표시합니다.
     4. 노트북이 Bluetooth로 배리어게이트에 개방 명령을 전송하고, 게이트가 열립니다.
     5. 개방 후 일정 시간이 지나면 게이트가 자동으로 닫힙니다.
   - **등록되지 않은 인물**인 경우
     1. 출입 불가 메시지를 표시하고 출입을 제한합니다.
     2. 배리어게이트는 잠금 상태를 유지합니다.
4. 출퇴근 기록을 서버에 저장합니다.
5. 노트북 웹에서 작업자의 출입 기록을 실시간으로 표시합니다.

## Scenario 2. 물류센터 순찰

1. 관제에서 순찰 명령이 내려오면 로봇은 지정된 순찰 경로를 따라 이동합니다.
2. 이동 중 정적·동적 장애물을 인식하면 다음을 수행합니다.
   - **정적 장애물 감지 시**
     1. 카메라로 응급 상황인지 일반 정적 장애물인지 판단합니다.
     2. 응급 상황이 아닌 일반 정적 장애물은 새 경로를 생성합니다.
     3. 장애물을 우회해 순찰을 지속합니다.
   - **동적 장애물 감지 시**
     1. 즉시 정지한 뒤 5초간 대기합니다.
     2. 동적 장애물이 사라지면 순찰을 재개합니다.
3. 순찰 중 작업장 환경을 모니터링합니다.
4. 순찰이 완료되면 충전 장소로 이동해 다음 순찰 임무를 대기합니다.

## Scenario 3. 안전모 미착용 감지 — 규정 위반

1. 작업자가 작업 구역에서 작업을 수행합니다.
2. 글로벌 관제 카메라 또는 순찰 중인 로봇이 작업자를 촬영합니다.
3. AI 객체인식 시스템이 안전모 착용 여부를 판단합니다.
   - **안전모 착용**: 정상 상태로 판단합니다.
   - **안전모 미착용**: 규정 위반으로 판단하고 다음을 수행합니다.
     1. 발견 주체에 따라 증거 사진을 확보합니다.
        - 글로벌 관제 카메라가 발견한 경우: 로봇을 해당 위치로 파견하고, 도착 후 증거 사진을 촬영합니다.
        - 순찰 중인 로봇이 발견한 경우: 즉시 정지해 현재 위치에서 증거 사진을 촬영합니다.
     2. 위반 사진과 발생 시간·위치를 서버에 저장합니다.
     3. 관제 시스템에 경고 알림을 전송합니다.
4. 서버는 스피커로 안전모 미착용 직원에게 안전모 착용을 안내합니다.
5. 관제 시스템은 규정 위반 정보를 표시합니다.
6. 관제자가 확인 후 순찰 재개를 명령하면 로봇은 순찰을 재개합니다.

## Scenario 4. 응급 사항 감지 — 화재·작업자 쓰러짐

1. 글로벌 관제 카메라 또는 순찰 중인 로봇이 현장을 촬영합니다.
2. AI 객체인식 시스템이 응급 사항을 판단합니다.
   - **정상 상태**: 순찰을 계속 수행합니다.
   - **쓰러짐 또는 화재 감지**: 응급 상황으로 판단하고 다음을 수행합니다.
     1. 발견 주체에 따라 현장 사진을 확보합니다.
        - 글로벌 관제 카메라가 발견한 경우: 로봇을 해당 위치로 긴급 파견하고, 도착 후 현장 사진을 촬영합니다.
        - 순찰 중인 로봇이 발견한 경우: 즉시 정지해 현재 위치에서 현장 사진을 촬영합니다.
     2. 당시 사진을 저장합니다.
     3. 관제 시스템에 응급 알림을 전송합니다.
     4. 로봇은 해당 위치에서 대기합니다.
3. 서버는 스피커로 화재 및 작업자 쓰러짐을 방송합니다.
4. 관리자가 상황을 확인하고 해결한 후 순찰 재개를 명령하면 로봇은 순찰을 재개합니다.

## Scenario 5. 자동 충전과 순찰 교대

1. 로봇은 배터리 상태를 지속적으로 확인합니다.
2. 배터리 잔량이 기준 이하인 **33%**가 되면 충전 모드로 전환합니다.
   - 작업 수행 중인 경우 현재 작업을 중단하고 충전 스테이션으로 이동합니다.
   - 충전 스테이션에 도착하면 다른 로봇이 이전 로봇의 남은 순찰을 이어서 진행합니다.
3. 로봇은 충전 스테이션에 도킹합니다.
4. 충전이 완료되면 대기 상태로 전환합니다.
5. 새로운 작업 요청이 들어오면 임무를 수행합니다.

## Scenario 6. 관제 서버 수동 조작 및 긴급 정지

1. 관제자는 로봇 상태를 실시간으로 모니터링합니다.
2. 이상 상황이 발생하면 관제자는 수동 제어 모드로 전환합니다.
3. 관제자는 GUI를 통해 로봇을 직접 조작합니다.
   - 전진
   - 후진
   - 좌회전
   - 우회전
   - 정지
4. 긴급 상황이 발생하면 관제자는 긴급 정지 버튼을 누릅니다.
   1. 로봇은 즉시 정지합니다.
   2. 현재 임무를 중단합니다.
   3. 관제 시스템에 긴급 정지 상태를 표시합니다.
5. 관제자가 재개 명령을 수행하면 로봇은 중단된 임무를 이어서 수행합니다.
